## 2. 核心业务全逻辑流程 (Logic Flow)

系统运行的核心逻辑可以概括为以下 **4 个阶段**：

### 第一阶段：账号授权与预热
1. **用户操作**：在前端点击“绑定百家号”。
2. **后端逻辑**：根据百家号配置，生成授权 URL。用户登录成功后，后端截获 `code` 或 `token`，存入 `account` 表。
3. **预热**：系统后台自动拉取该账号的分类（Category）信息和标签规范。

### 第二阶段：内容创作与多媒体洗涤
1. **内容输入**：用户在 `vue_view` 使用富文本编辑器写稿，插入本地图片。
2. **洗涤逻辑**：
   - 后端扫描文章，提取所有 `<img>` 标签。
   - 自动调整图片分辨率，符合各平台限制。
   - 将图片上传到服务器临时区。

### 第三阶段：多端适配与异步发布 (关键)
1. **用户触发**：选择 3 个百家号账号、1 个企鹅号账号，点击“一键发布”。
2. **任务拆解**：系统生成 4 个独立的 `PublishTask`，进入 Redis 队列。
3. **适配器执行**：后台引擎逐一取出任务，调用对应平台的 `Adapter`：
   - **Step A**: 调用平台 API 先把文章里的图片传上去，换回平台域名的 URL。
   - **Step B**: 替换文章源码中的图片地址，保持平台兼容性。
   - **Step C**: 提交最终 HTML 到发布接口。

### 第四阶段：状态追踪与结果回填
1. **监听**：通过定时任务或平台回调（Webhook），获取文章的审核状态（审核中、通过、拒绝）。
2. **反馈**：将结果（包括文章链接或拒绝原因）更新到 `PublishTask`。用户在前端界面实时刷新即可看到“发布成功”。
